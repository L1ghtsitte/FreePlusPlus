## Что такое `if`

`if` - конструкция, которая выполняет блок кода только если условие истинно (`true` / `1`). Если условие ложно (`false` / `0`) - блок пропускается.

Синтаксис:

```cpp
if (условие) {
    // выполнится если условие true
}
```

Условие - любое выражение, которое даёт тип данных `bool`. Это может быть сравнение, логическая операция, переменная `bool`, или число - `0` это `false`, всё остальное `true` / `1`.

---

## Примеры


```cpp
int if_a = 10;

if (if_a > 5) {
    // 10 > 5 это true - блок выполнится
    std::cout << "if_a больше 5" << std::endl;  // выведет
}

if (if_a > 20) {
    // 10 > 20 это false - блок пропустится
    std::cout << "if_a больше 20" << std::endl;  // не выведет
}
```

```cpp
bool if_b = true;

if (if_b) {
    // переменная уже bool - условие само по себе
    std::cout << "if_b истинно" << std::endl;  // выведет
}
```

```cpp
int if_c = 0;

if (if_c) {
    // 0 это false - блок пропустится
    std::cout << "не выведется" << std::endl;
}

int if_d = 42;

if (if_d) {
    // 42 это не 0, значит true
    std::cout << "if_d не ноль" << std::endl;  // выведет
}
```

```cpp
int if_e = 15;

// Несколько условий через &&
if (if_e > 10 && if_e < 20) {
    // оба условия true - блок выполнится
    std::cout << "if_e в диапазоне 10-20" << std::endl;  // выведет
}

// Условие через ||
if (if_e < 5 || if_e > 10) {
    // второе условие true - блок выполнится
    std::cout << "if_e меньше 5 или больше 10" << std::endl;  // выведет
}
```

## Скобки - обязательно

Если в блоке только одна строка - скобки можно не писать. Но это ловушка:

```cpp
int if_f = 5;

// Выглядит как две строки в if - но вторая всегда выполнится:
if (if_f > 0)
    std::cout << "положительное" << std::endl;
    std::cout << "это не в if!" << std::endl;  // выполнится всегда

// Правильно - со скобками:
if (if_f > 0) {
    std::cout << "положительное" << std::endl;
}
```

Всегда пиши фигурные скобки - даже если строка одна. Когда добавишь вторую строку - не забудешь скобки.

## Таблица - как вычисляется условие

|Выражение|Тип|Результат|Блок выполнится?|
|---|---|---|---|
|`5 > 3`|сравнение|`true`|✅|
|`5 < 3`|сравнение|`false`|❌|
|`5 == 5`|сравнение|`true`|✅|
|`5 != 5`|сравнение|`false`|❌|
|`true`|bool|`true`|✅|
|`false`|bool|`false`|❌|
|`42`|int|`true` (не ноль)|✅|
|`0`|int|`false`|❌|
|`-1`|int|`true` (не ноль)|✅|
|`a > 0 && b > 0`|логика|`true` если оба `true`|зависит|
|`a > 0 \| b > 0`|логика|`true` если хоть одно `true`|зависит|

---

## Типичные ошибки

|Ошибка|Что происходит|
|---|---|
|`if (x = 5)` вместо `if (x == 5)`|Присваивание вместо сравнения. x станет 5, условие всегда true (если 5 != 0)|
|`if` без фигурных скобок|Только следующая строка в блоке, остальные выполнятся всегда|
|Сравнение float через `==`|Погрешность double даёт неожиданные false. Лучше `fabs(a - b) < 0.00001`|
