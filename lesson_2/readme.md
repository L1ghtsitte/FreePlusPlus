## Операторы

Оператор - символ, который говорит компилятору что сделать с данными. Разбиваем по группам.

---

### Арифметические операторы

Объявляем две переменные - `a = 10` и `b = 3`. Дальше всё на них:

```cpp
int a = 10;
int b = 3;

int sum  = a + b;  // 13
int diff = a - b;  // 7
int mul  = a * b;  // 30
int div  = a / b;  // 3  - не 3.333, об этом ниже
int mod  = a % b;  // 1  - остаток от деления
```

Выводим:

```cpp
std::cout << sum  << std::endl;  // 13
std::cout << diff << std::endl;  // 7
std::cout << mul  << std::endl;  // 30
std::cout << div  << std::endl;  // 3
std::cout << mod  << std::endl;  // 1
```

**Целочисленное деление.** Когда делишь `int` на `int` - дробная часть отбрасывается без округления. Берём `x = 7` и `y = 2`:

```cpp
int x = 7;
int y = 2;

int    r1 = x / y;         // 3    - дробь выброшена
float  r2 = (float)x / y;  // 3.5  - x приведён к float
double r3 = 7.0 / 2;       // 3.5  - литерал 7.0 уже дробный

std::cout << r1 << std::endl;  // 3
std::cout << r2 << std::endl;  // 3.5
std::cout << r3 << std::endl;  // 3.5
```

`(float)x` - приведение типа. Говорит компилятору обращаться с `x` как с `float` в этом выражении. Саму переменную не меняет.

**Остаток от деления `%`.** Только для целых. Возвращает то, что осталось после деления нацело:

```cpp
int r4 = 17 % 5;  // 2  - 17 = 5*3 + 2, остаток 2
int r5 = 10 % 2;  // 0  - делится без остатка
int r6 =  3 % 7;  // 3  - делитель больше числа, результат само число

std::cout << r4 << std::endl;  // 2
std::cout << r5 << std::endl;  // 0
std::cout << r6 << std::endl;  // 3
```

### Операторы сравнения

Возвращают `bool` - `true` или `false`. В консоль выводится `1` или `0`.

Берём `w1 = 5` и `w2 = 10`:

```cpp
int w1 = 5;
int w2 = 10;

bool w3 = (w1 == w2);  // 0 - 5 не равно 10
bool w4 = (w1 != w2);  // 1 - 5 действительно не равно 10
bool w5 = (w1 >  w2);  // 0 - 5 не больше 10
bool w6 = (w1 <  w2);  // 1 - 5 меньше 10
bool w7 = (w1 >= w2);  // 0 - 5 не больше и не равно 10
bool w8 = (w1 <= w2);  // 1 - 5 меньше 10, условие выполнено

std::cout << w3 << std::endl;  // 0
std::cout << w4 << std::endl;  // 1
std::cout << w5 << std::endl;  // 0
std::cout << w6 << std::endl;  // 1
std::cout << w7 << std::endl;  // 0
std::cout << w8 << std::endl;  // 1
```

**`=` и `==` - разные операторы.** `=` присваивает, `==` сравнивает:

```cpp
int w9 = 10;

w9 = 3;    // w9 теперь 3 - присвоили новое значение
std::cout << w9 << std::endl;  // 3

w9 == 10;  // сравнение, вернёт false, но результат никуда не записан
```

Компилятор код с `w9 = 0` внутри `if` соберёт - ошибки не будет. Программа просто будет работать не так, как ты ожидаешь.

### Логические операторы

Объединяют несколько условий.

`&&` - И. `true` только если оба условия `true`.

Берём `age = 20` и `has_ticket = true`:

```cpp
int  age        = 20;
bool has_ticket = true;

bool q1 = (age >= 18) && has_ticket;   // 1 - оба выполнены
bool q2 = (age >= 18) && !has_ticket;  // 0 - второе не выполнено
bool q3 = (age <= 18) && has_ticket;   // 0 - первое не выполнено

std::cout << q1 << std::endl;  // 1
std::cout << q2 << std::endl;  // 0
std::cout << q3 << std::endl;  // 0
```

`||`- ИЛИ. `true` если хотя бы одно условие `true`.

Берём `score = 45`:

```cpp
int score = 45;

bool q4 = (score >= 50) || (score == 45);  // 1 - второе выполнено
bool q5 = (score >= 90) || (score <= 10);  // 0 - оба не выполнены

std::cout << q4 << std::endl;  // 1
std::cout << q5 << std::endl;  // 0
```

**`!` - НЕ. Инвертирует значение.**

```cpp
bool is_online = false;

bool q6 = !is_online;   // true  - инвертировали false
bool q7 = !!is_online;  // false - инвертировали дважды, вернулись к исходному

std::cout << q6 << std::endl;  // 1
std::cout << q7 << std::endl;  // 0
```

**Приоритет:** сначала `!`, потом `&&`, потом `||` - как в математике умножение раньше сложения. Когда условий много - ставь скобки явно, чтобы не гадать.

### Побитовые операторы

Работают с числом не целиком, а побитово - с каждым битом двоичного представления по отдельности.

**`&` - побитовое И.** Бит результата `1`, только если оба бита `1`:

```
  0000 0110  (6)
& 0000 0011  (3)
-----------
  0000 0010  (2)
```

```cpp
int q8 = 6 & 3;  // 2
std::cout << q8 << std::endl;  // 2
```

`|` - побитовое ИЛИ.Бит `1` если хотя бы один бит `1`:

```
  0000 0110  (6)
| 0000 0011  (3)
-----------
  0000 0111  (7)
```

```cpp
int q9 = 6 | 3;  // 7
std::cout << q9 << std::endl;  // 7
```

`^` - XOR. Бит `1` если биты **разные**:

```
  0000 0110  (6)
^ 0000 0011  (3)
-----------
  0000 0101  (5)
```

```cpp
int q10 = 6 ^ 3;  // 5
std::cout << q10 << std::endl;  // 5
```

`~` - побитовое НЕ. Инвертирует все биты. Для `6` это выглядит так:

```
 00000000 00000000 00000000 00000110  (6)
 11111111 11111111 11111111 11111001  (-7)
```

```cpp
int q11 = ~6;  // -7
std::cout << q11 << std::endl;  // -7
```

Получается `-7`, потому что целые числа хранятся в дополнительном коде. Это тема отдельного разговора, пока просто запомни результат.

`<<` и `>>` - сдвиги.*Двигают все биты влево или вправо:

```
6 → 0000 0110
6 << 1 → 0000 1100  (12) - умножение на 2
6 >> 1 → 0000 0011  (3)  - деление на 2 нацело
```

```cpp
int sd1 = 6 << 1;  // 12
int sd2 = 6 >> 1;  // 3
int sd3 = 1 << 4;  // 16  - 0000 0001 → 0001 0000
int sd4 = 1 << 8;  // 256 - удобный способ получать степени двойки

std::cout << sd1 << std::endl;  // 12
std::cout << sd2 << std::endl;  // 3
std::cout << sd3 << std::endl;  // 16
std::cout << sd4 << std::endl;  // 256
```

Побитовые операторы встречаются в системном коде, работе с флагами и оптимизациях. На курсе ещё будут.

## Сокращённые операторы присваивания

Запись `x = x + что-то` встречается постоянно. Для неё есть короткий вариант.

Объявляем переменные:

```cpp
int f1 = 7;
int f2 = 9;
int f3 = 3;
int f4 = 5;
int f5 = 17;
```

Полная запись и сокращённая - одно и то же:

```cpp
f1 += 3;  // f1 = f1 + 3  = 10
f2 -= 4;  // f2 = f2 - 4  = 5
f3 *= 2;  // f3 = f3 * 2  = 6
f4 /= 2;  // f4 = f4 / 2  = 2
f5 %= 5;  // f5 = f5 % 5  = 2

std::cout << f1 << std::endl;  // 10
std::cout << f2 << std::endl;  // 5
std::cout << f3 << std::endl;  // 6
std::cout << f4 << std::endl;  // 2
std::cout << f5 << std::endl;  // 2
```

То же самое для побитовых. Берём `f6 = 6` и делаем операции по цепочке - каждая следующая работает с результатом предыдущей:

```cpp
int f6 = 6;

f6 &= 3;   // 6 & 3   = 2
f6 |= 5;   // 2 | 5   = 7
f6 ^= 1;   // 7 ^ 1   = 6
f6 <<= 2;  // 6 << 2  = 24
f6 >>= 1;  // 24 >> 1 = 12

std::cout << f6 << std::endl;  // после каждой строки: 2, 7, 6, 24, 12
```

## Инкремент и декремент

`++` - увеличить на 1, `--` - уменьшить на 1. Ставятся до или после переменной - и это разные вещи.

|Форма|Синтаксис|Порядок|Возвращает|
|---|---|---|---|
|Префиксный|`++x`, `--x`|сначала изменить, потом использовать|новое значение|
|Постфиксный|`x++`, `x--`|сначала использовать, потом изменить|старое значение|

**Если оператор стоит отдельно - разницы нет:**

```cpp
int y1 = 5;

y1++;  // y1 = 6
++y1;  // y1 = 7
y1--;  // y1 = 6
--y1;  // y1 = 5
```

**Разница появляется, когда результат используется сразу.**

Префикс `++y2` - сначала увеличивает, потом возвращает:

```cpp
int y2 = 5;
int y3 = ++y2;  // y2 сразу стало 6, y3 = 6

std::cout << y2 << ' ' << y3 << std::endl;  // 6 6
```

Постфикс `y4++` - сначала возвращает текущее, потом увеличивает:

```cpp
int y4 = 5;
int y5 = y4++;  // y5 = 5 (старое), потом y4 стало 6

std::cout << y4 << ' ' << y5 << std::endl;  // 6 5
```

Декремент - то же самое, только в минус:

```cpp
int y6 = 10;
int y7 = --y6;  // y6 сразу стало 9, y7 = 9

std::cout << y6 << ' ' << y7 << std::endl;  // 9 9

int y8 = 10;
int y9 = y8--;  // y9 = 10 (старое), потом y8 стало 9

std::cout << y8 << ' ' << y9 << std::endl;  // 9 10
```

## Константы

Переменная - значение, которое можно менять. Константа - значение, которое зафиксировано после инициализации. Есть два варианта: `const` и `constexpr`.

---

### `const`

```cpp
const float PI = 3.14159265;
```

Попытка изменить - ошибка компиляции:

```cpp
PI = 3.0;  // error: assignment of read-only variable 'PI'
```

Объявить без значения нельзя:

```cpp
const int x;      // ошибка
const int y = 5;  // ok
```

---

### `constexpr`

Строже. Значение должно быть известно **на этапе компиляции** - до запуска программы:

```cpp
constexpr double GRAVITY    = 9.81;
constexpr int    MAX_PLAYER = 8;
```

Если значение известно только в рантайме - ошибка:

```cpp
int n;
std::cin >> n;

constexpr int size  = n;  // ошибка - n неизвестно при компиляции
const     int size2 = n;  // ok
```

---

### Зачем это нужно

Вот конкретный пример. Есть вычисление с `GRAVITY`:

```cpp
double force = mass * 9.81;   // что такое 9.81? непонятно без контекста
double force = mass * GRAVITY; // сразу понятно
```

То же с `MAX_PLAYER`. Если это значение используется в 20 местах по всей программе - менять надо только одну строку, а не искать число `8` по всему коду:

```cpp
constexpr int MAX_PLAYER = 8;
// ... всюду используется MAX_PLAYER ...

constexpr int MAX_PLAYER = 16;  // поменял здесь - обновилось везде
```

---

### Разница между `const` и `constexpr`

|`const`|`constexpr`|
|---|---|---|
|Изменить после инициализации|Нет|Нет|
|Когда вычисляется|При компиляции или при запуске|Только при компиляции|
|Зависит от ввода пользователя|Да|Нет|

Простое правило: если значение можно написать прямо в коде и оно ни от чего не зависит - `constexpr`. Если появляется только во время работы программы - `const`.

---

### Соглашение по именованию

Константы принято писать ЗАГЛАВНЫМИ_БУКВАМИ_ЧЕРЕЗ_НИЖНЕЕ_ПОДЧЁРКИВАНИЕ. Это не требование языка - общепринятое соглашение. Когда видишь такое имя - сразу понятно что это константа:

```cpp
const    float  PI         = 3.14159265;
constexpr double GRAVITY    = 9.81;
constexpr int    MAX_PLAYER = 8;
```

## Итог

- **Арифметика** - `+`, `-`, `*`, `/`, `%`. При делении двух `int` дробная часть отбрасывается.
- **Сравнение** - `==`, `!=`, `>`, `<`, `>=`, `<=`. Не путать `=` и `==`.
- **Логика** - `&&`, `||`, `!`. Приоритет: `!` → `&&` → `||`.
- **Побитовые** - `&`, `|`, `^`, `~`, `<<`, `>>`. Работают с битами числа.
- **Сокращённые операторы** - `+=`, `-=`, `*=`, `/=`, `%=` и побитовые варианты.
- **Инкремент/декремент** - `++`, `--`. Префикс меняет до использования, постфикс - после.
- `const` - фиксирует значение, может вычисляться в рантайме.
- `constexpr` - фиксирует значение, вычисляется при компиляции. Строже и быстрее.

### Инкремент и декремент

| Запись | Название              | Возвращает      | Пример (x = 5) | x после | результат |
| ------ | --------------------- | --------------- | -------------- | ------- | --------- |
| `++x`  | Префиксный инкремент  | новое значение  | `y = ++x`      | `6`     | `y = 6`   |
| `x++`  | Постфиксный инкремент | старое значение | `y = x++`      | `6`     | `y = 5`   |
| `--x`  | Префиксный декремент  | новое значение  | `y = --x`      | `4`     | `y = 4`   |
| `x--`  | Постфиксный декремент | старое значение | `y = x--`      | `4`     | `y = 5`   |
